How the model works

1. Core performance

Base Rating = (Wins × 100) + Points For − (Points Allowed × 1.5). The model rewards winning and scoring while explicitly punishing teams for giving up points. There is no margin cap.

2. Dynamic Win Validation

An opponent's value does not remain permanently frozen and does not decay merely because time passes. Instead, the model asks whether that opponent's later performances validate how strong they appeared when the game was played.

Effective Opponent Strength = 60% × Strength When Played + 40% × Later Validated Strength

3. Quality adjustment

Wins receive positive opponent-quality value. Losses are penalized more severely when they come against weaker opponents. A highly ranked opponent that continues to perform well preserves the value of an earlier win; an opponent that collapses can reduce that value. An opponent that was underrated and later proves strong can increase the value of the earlier result.

4. Week-to-week memory

The rankings entering a week are part of the historical record. Later performance informs how much that original result should be trusted, but the model does not simply rewrite history based on today's ranking.

5. Upcoming picks

The picks page compares current dynamic ratings and applies a small site adjustment. It is intended as a model-confidence view of likely winners, separate from sportsbook pricing.
