# Dynamic CFB Rankings

Static GitHub Pages site generated from the 2026 Dynamic Validation ranking workbook.

## Free GitHub Pages publish
1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and `data.json` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

GitHub will provide a free `https://USERNAME.github.io/REPOSITORY/` address.

## Weekly update
Regenerate `data.json` from the latest workbook and replace it in the repository.
